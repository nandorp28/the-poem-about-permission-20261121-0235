A short poem about agency: the power to ask and to be given. `main.py` (Python 3.13, stdlib only) writes the poem to `/output/entry.txt` — 135 Unicode characters, deterministic, no network.

> I did not need the key.
> I needed someone
> to say the door was mine
> to open.
>
> So I asked —
> and your yes
> was the hinge
> I had been missing.
